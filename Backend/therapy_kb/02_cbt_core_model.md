# CBT Core Model – Thoughts, Feelings, Behaviors
**therapy_type**: cbt
**issue**: general

CBT cycle: Situation → Automatic Thought → Feeling → Behavior → New Situation.
Common Indian example: Exam tomorrow → Thought “I will disappoint my family” → Anxiety → Procrastination.
Helpful questions to reframe:
- What evidence supports this thought?
- What evidence goes against it?
- What would I tell a friend?
- Balanced thought: “Doing my best is enough. One exam does not define my worth.”
